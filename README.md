# Kirkova API Docs

Public documentation for the Kirkova Sports API (`https://kirkova.cc/v1`).

- [`api.md`](api.md): the full reference: authentication, public endpoints, scopes and responses.

Public endpoints (`/public/*`) need no key and are rate-limited by IP. Everything else needs an API key exchanged for a short-lived token.

Found a mistake in the docs, or an endpoint that doesn't behave as described? Please [open an issue](../../issues).
